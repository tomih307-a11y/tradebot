# تشغيل وحدة توصيات القناة على جهاز ويندوز (وضع ورقي — بلا أوامر حقيقية)

## 1) التثبيت (مرة واحدة)
1. نزّل Python من https://www.python.org/downloads/ وأثناء التثبيت **علّم على «Add python.exe to PATH»**.
2. نزّل المشروع: https://github.com/tomih307-a11y/tradebot/archive/refs/heads/claude/pmo-zero-crossing-strategy-tzs5l3.zip ثم فك الضغط.
3. افتح مجلد المشروع، واكتب في شريط العنوان `cmd` ثم Enter. في النافذة السوداء:
   ```
   pip install -r requirements.txt
   ```

## 2) الإعداد
افتح `config.toml` بالمفكرة (Notepad) وابحث عن `[telegram_signals]`، ثم:
```
channel = "اسم_القناة"        # الجزء بعد t.me/  (القناة العامة فقط)
```
الباقي مضبوط: هامش 10% من الرصيد، صفقتان كحد أقصى، رصيد ورقي 25$، وقف بقاعدة القناة (إغلاق شمعة 4 ساعات).

## 3) التشغيل (ورقي)
```
python -m tradebot --strategy telegram_signals live
```
- لا يفتح صفقات من الرسائل القديمة؛ يبدأ من آخر رسالة.
- كل دخول/هدف/إغلاق يظهر في النافذة (ويصلك على Telegram إن ضبطت `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID`).
- سجل الصفقات المغلقة: `reports\telegram_signals_trades.csv`.
- يحتاج أن يبقى الجهاز والإنترنت شغالين. أوقف الشاشة فقط، وعطّل السكون.

## 4) اختبار تاريخ القناة على أسعار MEXC (الأهم قبل أي مال)
1. على **Telegram Desktop**: افتح القناة ← ⋮ ← **Export chat history** ← صيغة **JSON** ← نزّل بدون وسائط.
2. أرسل لي الملف `result.json` (أو شغّل بنفسك):
   ```
   python -m tradebot --strategy telegram_signals backtest --history result.json --delay 60
   ```
   `--delay` = ثواني بين نشر التوصية ودخولك (جرّب 30 و60 و180).
3. النتيجة: `reports\telegram\signals_report.md` و`signals_backtest.csv`.

## الواجهة الرسومية
انقر مرتين على `run_gui.bat` (أو `python -m tradebot gui`)، اكتب اسم القناة، واضغط «ابدأ».
تعرض الواجهة الرصيد والصفقات المفتوحة وسجل الأحداث. الوضع **ورقي** (محاكاة بأسعار MEXC الحقيقية) ولا ترسل أوامر حقيقية.

## التنفيذ الحقيقي (أوامر فعلية على MEXC)
1. في MEXC أنشئ مفتاح API للعقود: صلاحيات **قراءة + تداول فقط، بدون سحب**، وقيّده بعنوان IP جهازك إن أمكن.
2. ضع المفتاح على جهازك فقط (لا ترسله لأحد):
   `setx MEXC_API_KEY "..."` و `setx MEXC_API_SECRET "..."` ثم أعد فتح الطرفية.
3. في `config.toml` غيّر `[trading] dry_run = false`.
4. جرّب أولاً بالورقي أياماً، ثم شغّل الحقيقي. العنوان في الواجهة يتحول إلى «تنفيذ حقيقي».

ما يفعله: دخول بأمر سوق، هامش معزول 10% من الرصيد، أهداف كأوامر حد (reduce-only) بحصص متساوية،
بعد الهدف الأول ينتقل الوقف لسعر الدخول، وقف القناة (إغلاق شمعة 4س) ينفَّذ بأمر سوق.
إذا فشل وضع أي حماية بعد الدخول يُغلق المركز فوراً. للإيقاف الطارئ أغلق النافذة واغلق المراكز من تطبيق MEXC.
تنبيه: هذا الكود لم يُجرَّب على حساب حقيقي بعد، وصيغ أوامر MEXC فيه حسب التوثيق. ابدأ بمبلغ صغير وراقب أول صفقة.

## قناة خاصة (بدون اسم مستخدم) — قراءة بحسابك
1. ادخل https://my.telegram.org بحسابك ← API development tools ← أنشئ تطبيقاً، وانسخ `api_id` و`api_hash`. **لا ترسلهما لأحد.**
2. `pip install telethon`
3. `setx TG_API_ID "..."` و `setx TG_API_HASH "..."` ثم أعد فتح الطرفية.
4. `python -m tradebot tg-login` — يطلب رقم هاتفك والكود الذي يصلك على تلقرام (تكتبهما هنا على جهازك فقط). يطبع قائمة قنواتك بأرقامها.
5. رقم قناتك في `config.toml` (`channel = "-1002639765041"`)، ثم شغّل `run_gui.bat`.
ملف الجلسة `state/tg_session.session` يمنح صلاحية على حسابك: لا تشاركه ولا ترفعه إلى GitHub.

## وضع الوكلاء الخمسة (بدون قناة)
`python -m tradebot --strategy multi_agent live` — نفس حدود الهامش (10%) والصفقات (2) ونفس الوضع الورقي/الحقيقي (`dry_run`).
1. **الماسح**: يرتّب عقود MEXC حسب السيولة والحركة.  2. **المحلل الفني**: اتجاه 4س + ارتداد 1س → توصية بمنطقة دخول ووقف وأهداف من ATR.
3. **محلل الأخبار**: عناوين RSS (وClaude اختيارياً بـ `ANTHROPIC_API_KEY` و`use_claude = true`) → يرفض أو يعزّز.
4. **وكيل الدخول**: ينتظر منطقة الدخول وتأكيد شموع الدقيقة، ولا يطارد.  5. **وكيل الخروج**: وقف متحرك بعد الهدف الأول، قطع الصفقة الراكدة، وتشديد/إغلاق عند خبر عكسي.
كل الأرقام في `config.toml` قسم `[agents]`. لا باكتست (الأخبار التاريخية غير متاحة): قيّمه بالورقي أولاً.

## تعاون الوكلاء الستة (بدون القناة)
`python -m tradebot --strategy multi_agent live` — القناة معطّلة في هذا الوضع (`[agents.channel] enabled = false`).
1. الماسح يختار العملات، 2. المحلل الفني يبني التوصية، 3. الأخبار تقيّمها، 4. وكيل الخروج يقيّم المخاطرة/العائد قبل النشر.
كل وكيل **يصوّت 0..1 وقد يضع فيتو**؛ لا تُنشر التوصية إلا إذا بلغت الثقة المرجّحة `min_confidence` (الأوزان في `[agents.consensus]`) ولم يعترض أحد.
5. وكيل الدخول ينتظر التوقيت المناسب، 6. **وكيل التنفيذ** (`execution.py`) هو الوحيد الذي يلمس المنصة؛ `[agents.execution] enabled = false` ينشر التوصيات فقط بلا صفقات.
كل توصية منشورة تُسجَّل في `reports/agents_ledger.csv` مع تصويت كل وكيل ونتيجتها عند الإغلاق، لنعرف لاحقاً أي وكيل يصيب فنعدّل الأوزان.
لإضافة وكيل تنفيذ خاص بك: اكتب صنفاً بنفس الدوال (`can_open/open/move_stop/close`) ومرّره `Orchestrator(..., execution=MyAgent)`.
(الدمج مع توصيات القناة ما زال متاحاً باختيار `[agents.channel] enabled = true`.)

## تحليل SMC
في `[agents] analyst = "smc"` (الافتراضي) يولّد **وكيل SMC** التوصيات، وتصوّت المؤشرات الكلاسيكية كرأي ثانٍ (`technical`).
- **الهيكل:** قمم/قيعان فراكتل؛ إغلاق شمعة خلف آخر قمة/قاع = BOS (مع الاتجاه) أو CHoCH (عكسه). القمة/القاع لا تُعتمد إلا بعد `swing_len` شموع (بلا نظر للمستقبل).
- **منطقة الدخول (POI):** Order Block = آخر شمعة معاكسة قبل الكسر، وإلا FVG (فجوة ثلاث شموع). تُقبل غير الملموسة فقط (السعر لم يعد إليها ولم يغلق خلفها).
- **الشروط (6):** اتجاه 4س يوافق، كسر هيكل حديث، منطقة غير ملموسة، تقاطع OB مع FVG، سعر في خصم (للشراء) أو علاوة (للبيع)، سحب سيولة. الحد الأدنى `min_score`.
- **المستويات:** الدخول عند أول حافة يلمسها السعر عند الارتداد، الوقف خلف الطرف الآخر بـ 0.3 ATR، الأهداف 1R و2R و3R.
- وكيل الدخول يرصد عودة السعر للمنطقة (ولا يعتبر البعد عنها «ركضاً») ثم يؤكد بشمعتين دقيقتين.
لاستعمال المؤشرات الكلاسيكية كمولّد بدلاً منه: `analyst = "technical"`.
